GitHub Mobile Actions 실패 Copilot 수정 지원
2026-07-23
설명
  • GitHub Mobile에서 실패한 GitHub Actions check를 Copilot coding agent에 바로 맡겨 수정할 수 있게 됐습니다.
  • pull request의 Actions check가 실패하면 사용자는 모바일에서 Fix with Copilot을 선택해 Copilot coding agent가 실패 원인을 분석하고 수정 pull request를 만들도록 할 수 있습니다. Copilot은 기존 PR 위에 새 PR을 열고 변경을 준비한 뒤 리뷰를 요청하므로, 이동 중에도 CI 실패 대응 흐름을 이어갈 수 있습니다.
