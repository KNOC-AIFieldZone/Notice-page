GitHub Code Quality is now generally available
2026-07-20
설명
  • GitHub Code Quality가 GA로 올라오며, AI-assisted detection과 Copilot Autofix를 포함한 코드 품질 검사가 정식 제품이 됐습니다.
  • GitHub Code Quality는 CodeQL의 정적 분석과 AI-assisted detection을 결합해 PR에서 유지보수성·신뢰성 문제를 찾고, Copilot Autofix가 수정 제안을 제공합니다. GA에서 조직 단위 활성화, org-level dashboards, 테스트 리포트 기반 code coverage metrics, GitHub rulesets 기반 quality gates, enablement/findings API가 추가됐습니다. GitHub Copilot 자체 기능만은 아니지만, 공식 GitHub AI-assisted 개발 워크플로 업데이트로 중요도가 높아 별도 카드로 포함했습니다.
