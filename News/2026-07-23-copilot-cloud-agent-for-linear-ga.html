Copilot cloud agent for Linear GA
2026-07-23
설명
  • GitHub가 Linear 이슈를 Copilot cloud agent에 맡기는 기능을 정식 출시했습니다.
  • Linear에서 이슈를 Copilot에 할당하면 Copilot이 내용을 분석해 draft pull request를 열고, GitHub Actions 기반 임시 개발 환경에서 독립적으로 작업하며, 진행 상황을 Linear activity timeline에 남깁니다. 사용자는 모델 선택, custom agent 지정, base/working branch 설정, 댓글을 통한 세션 지시까지 Linear 안에서 제어할 수 있습니다.
