GitHub Mobile: Improved filters and sorting for Copilot sessions
2026-07-10
설명
  • GitHub Mobile에서 Copilot 세션이 많아졌을 때 원하는 세션을 찾기 쉽게 필터와 정렬 기능이 강화됐습니다.
  • 세션 목록을 Active, Status, Repository, Type, Agent 기준으로 좁힐 수 있고, most recent, oldest, active first, needs-attention first 같은 정렬도 지원합니다. 단순 화면 미세 조정이라기보다, 모바일에서 Copilot 에이전트 세션을 계속 추적·관리하는 흐름에 직접 영향을 주는 기능으로 판단해 포함했습니다. 최신 iOS·Android GitHub Mobile production build에서 제공된다고 공지됐습니다.
