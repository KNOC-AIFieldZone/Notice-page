AlphaEvolve on Cloud is now generally available
2026-07-09
설명
  • Google이 Gemini 기반 코드 최적화 에이전트 AlphaEvolve on Cloud를 GA로 공개했습니다.
  • AlphaEvolve는 사용자가 baseline algorithm과 목표를 주면 더 나은 구현을 탐색하고 최적화된 코드를 제안하는 AI code-optimization agent입니다. Google은 이 기능이 Gemini Enterprise Agent Platform에서 모든 Google Cloud 고객에게 제공된다고 밝혔습니다. 첨부된 Gemini 카테고리 URL 자체가 아니라 Google Cloud/AI 공식 경로라 +1 탐색 항목으로 분리했습니다.
