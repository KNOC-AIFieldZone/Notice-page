Cursor 내 OpenAI 모델 지원 종료 예정
2026-08-28
설명
  • OpenAI가 Cursor에 자사 모델을 제공하는 계약을 단계적으로 종료할 방침이며, 제안된 지원 종료일은 2026년 11월 12일입니다.
  • 계약상 최대 통지 기간 동안 현재 모델 접근을 유지하되 향후 OpenAI 모델은 Cursor에 제공하지 않을 예정이어서, 해당 모델을 쓰는 개발자는 전환 준비가 필요합니다.
